# Right Level plugin

The plugin folder for Claude Code and the Codex app. It adds two hooks. At session start the agent gets the four levels (Indicate, Show, Explain, Elaborate). On every message it gets one short moment line with the cap, read from what you set, your own engine, your Mac and how you asked. Use `/right-level:attention` to set your attention by hand. Say `more` or `less` to move a reply one level. See the README at the repository root for install steps and how it works.
